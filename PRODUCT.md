# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop (Java Swing); not a web, iOS or Android surface.

## Users and Purpose

Chinese-speaking users convert their local KuGou audio files to high-quality MP3 with a portable Windows EXE and a command-line launcher.

## Capabilities and Constraints

Drag and drop, file/folder import, conversion queue, quality selection, output directory, cancellation, concurrent CPU encoding. KGG v5 needs a matching per-track key in the local KuGou database or a supplied key file. GPU detection must not claim GPU MP3 encoding. Preserve source files. Do not upload audio or database keys. Source license: MIT with third-party notices. GitHub repository: QXF19/kgg-mp3; build Windows releases using GitHub Actions.

## Brand Commitments

User explicitly requests an Apple-like feeling and selected Liquid Glass after rejecting the initial ordinary light preview. Use translucent app-rendered panels, restrained highlights and macOS-style controls while preserving Windows window management and the existing conversion workflow. Chinese interface, project name kgg-mp3. Do not claim native macOS compositor blur or refraction.

## Evidence

Existing Swing implementation and a successfully converted real KGG v5 sample. Private sample audio stays outside Git.
