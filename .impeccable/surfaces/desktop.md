# Desktop converter

Mode: Operate. Native Windows Swing, preserving native window management.

## Direction contract

THESIS: A quiet macOS-inspired workspace for importing audio and converting it locally.

OWN-WORLD: User-selected Liquid Glass-inspired material: procedural pale blue/violet backdrop, translucent white panels, layered white rim highlights and pointer-responsive specular light. FlatMacLightLaf supplies macOS-style controls; Chinese type remains dark and readable. This is app-rendered glass styling, not native macOS compositor blur.

STORY: import music; see file/state/progress in a real table; select output and quality; convert; open the resulting folder.

FIRST VIEWPORT: 190px sidebar, 26pt main heading, 230px import area above an expanding music queue. A separate 250px settings inspector places quality, output, concurrency and the primary action on the right. FlatMacLightLaf controls, 14pt default font and white workspace. Empty queue teaches the right-side action. Minimum window 1080x740.

FORM: User-pinned Apple-like direction overrides random assignment (seed 9b77fb3e). Code-led existing Swing surface; no image comp or unconfirmed persistent workflow preference. Signature move: blue import arrow and blue selection guide import-to-output without decorative chrome.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
